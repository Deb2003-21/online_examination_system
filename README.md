# Exam Project

An online examination system built with **React**, **PHP**, and **MySQL**, offering a seamless and interactive platform for online exams. This project incorporates real-time communication, attendance tracking, time submission, and leaderboard functionality, ensuring a comprehensive solution for both teachers and students.

## Features

- **Real-time Communication**:
  - Teachers and students can interact in real-time using **WebSocket**.
  
- **Authentication**:
  - Password validation via **SMTP** for secure email verification.

- **Attendance Tracking**:
  - Tracks student attendance during exams and ensures accountability.

- **Time Submission**:
  - Monitors exam duration and ensures timely submission of answers.

- **Leaderboard**:
  - Displays scores and rankings in a dynamic leaderboard.

- **Frontend**:
  - Built with **React** and styled using **Tailwind CSS** for a modern and responsive UI.

## Technology Stack

### Frontend
- **React**
- **Tailwind CSS**

### Backend
- **PHP**

### Database
- **MySQL**

### Other Tools
- **WebSocket** for real-time communication.
- **SMTP** for email password validation.
  

## Installation & Setup

### Requirements
- **Node.js** 14.x or higher
- **npm/yarn** (for React dependencies)
- **composer**

### Steps to Install

#### 1. Clone the repository
```bash
git clone https://github.com/Deb2003-21/online_examination_system.git
cd online_examination_system/exam-project
```

#### 2. Install Dependencies
- Install React dependencies:
  ```bash
  npm install
  ```

#### 3. Run the Development Server
- Start the development server:
  ```bash
  npm start
  ```

#### 4. Backend Integration
Ensure the backend server is set up as per the main project instructions.

#### 5. Database Integration
Ensure the database is configured properly and connected to the backend.

  - Monitor attendance.
